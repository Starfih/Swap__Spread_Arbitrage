# Bloomberg Rates Data

Coverage: January 1, 2020–October 18, 2026.

- `GTGOV.xlsx`: 2Y, 5Y, 10Y U.S. Treasury quotes.
- `USGG.xlsx`: 2Y, 5Y, 10Y Treasury benchmark yields.
- `USGG_ext.xlsx`: 3Y, 7Y, 20Y, 30Y Treasury benchmark yields.
- `USOSFR.xlsx`: 2Y, 5Y, 10Y USD SOFR swaps.
- `USOSFR_ext.xlsx`: 3Y, 7Y, 20Y, 30Y USD SOFR swaps.
- `ONF_MR.xlsx`: SOFR, Fed Funds, MOVE, and VIX.
